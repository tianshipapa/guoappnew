# 短剧视界 (HongGuoJian / ZhenGuoJian) - React Web Edition

跨平台多端独立短剧与影视聚合播放器，由原 Flutter 架构完整重构为现代化 React + TypeScript + Vite + Tailwind CSS 应用，完整保留全部核心业务逻辑与功能特性。

## ✨ 核心特性与业务逻辑

1. **多站源聚合与切换 (Multi-Source Hub)**：
   - 内置红果（短剧/漫剧/AI剧）、红果新（免签名新版取流）、剧果、野果、帝果、黄豆、A123、爱看机器人、韩小圈、鬼片、青空及短剧家族系列源（芽果、猫果、饭果、观果、河果、星果、花果等）。
   - 支持动态管理自定义源（MacCMS JSON、XML、网页采集源），具备接口连通性测试与快速启用。
   - 源显示列表：可按需显示或隐藏任意内置与自定义站源。

2. **分类浏览与智能排序筛选**：
   - 支持全部分类快速滑动切换：全部、推荐、都市、逆袭、战神、战神神豪、甜宠、古装、穿越、重生、悬疑、漫剧、AI 剧等。
   - 排序与筛选：支持默认排序、热度最高、播放量最多、最新上线、剧集季号，以及连载中 / 已完结连载状态筛选。

3. **全源并发聚合搜索与拼音首字母检索 (All-Sources & Pinyin Acronym Search)**：
   - **拼音首字母检索**：输入 `BDZC` 实时联想并检索「霸道总裁」，输入 `LWCY` 检索「龙王出狱」，内置 20,000+ 汉字 Unicode 拼音首字母映射表。
   - **全部源并发搜索**：支持勾选「全部源」，跨所有可见站源并发检索，按剧目标题与分集归一去重，展示所有拥有该剧副本的来源标签并支持在详情页一键切源。
   - **电视端软键盘**：内置 A-Z 与 0-9 虚拟字母键盘，方便电视遥控器或极简输入。
   - 实时搜索建议联想词与最近搜索历史记录管理。

4. **专业短剧播放器 (Professional Video Player)**：
   - 采用 HTML5 + HLS (hls.js) 双模流媒体引擎，兼容 `.m3u8` 与 MP4。
   - 多线路故障自动转移 (Failover)：线路 1/2/3 遇网络或流异常时自动平滑切线重试。
   - 自动连播下一集 (Auto-Next) 与手势/快捷键切集（方向键上/下切换前一集/后一集，空格键暂停/播放）。
   - 播放倍速：0.5x、0.75x、1.0x、1.25x、1.5x、2.0x、3.0x。
   - 画面锐化增强：动态对比度与边缘锐度增强滤镜。
   - 弹幕互动：全屏飘飞弹幕图层，支持多色弹幕即时发送与开关。

5. **剧集选集与剧目详情**：
   - 50集分组范围标签卡快速切换，支持选集正序/倒序排列，支持精准集数输入跳转。
   - 剧目海报、热度、播放量、完结状态、全网其他源副本切换展示。

6. **追剧与播放记录 (Watchlist & History)**：
   - 观看记录：记录精确进度（第几集、具体分秒与百分比进度条），支持一键继续播放与批量管理删除。
   - 我的追剧：按「在看」、「想看」、「已看」分类整理收藏。
   - 记录与收藏均支持拼音首字母实时检索。

7. **电视与网络直播 (Live TV)**：
   - 央视频道（CCTV-1、CCTV-6、CCTV-8、CCTV-13 等）。
   - 卫视频道（湖南卫视、浙江卫视、江苏卫视、东方卫视 等）。
   - 24 小时短剧轮播专区（逆袭战神热播剧场、甜宠虐恋千金剧场、经典动作短剧等）。

8. **偏好设置与存储管理**：
   - 自动连播、去广告、默认倍速、画面锐化强度调节。
   - 主题配色与电视字母键盘切换。
   - 本地缓存统计与一键清理重置。

## 🛠️ 技术栈

- **框架**：React 18 + TypeScript + Vite 6
- **样式**：Tailwind CSS + Lucide React 图标库
- **播放引擎**：Hls.js + HTML5 Media API
- **数据持久化**：LocalStorage 本地响应式存储
